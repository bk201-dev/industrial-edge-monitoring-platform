## Overview

This repository presents a sanitized engineering case study developed during my PFA internship at ELECT-CAD COMPANY.

The project focused on an embedded monitoring and communication platform for transformer cabinets, designed to bridge information already available inside the cabinet with industrial supervision and remote monitoring.

More than a PCB design exercise, the project brought together embedded processing, isolated industrial communication, cellular connectivity, data storage, power integrity, RF considerations, multilayer PCB design, and manufacturing constraints into one complete system.

> **Note**
> This repository intentionally excludes confidential production files, complete schematics, Gerbers, BOMs, firmware, customer specifications, and other proprietary implementation details.
